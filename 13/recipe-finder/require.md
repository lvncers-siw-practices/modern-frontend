# 第13回

# 1. 今回のゴール

今回のゴールは、ReactとTypeScriptを利用して、外部APIから取得したデータを扱うWebアプリケーションを自力で構築することです。

以下の機能を持つ「Recipe Finder」を作成します。

- 料理を検索できる
- 検索結果を一覧表示できる
- 料理の詳細を確認できる
- 気になる料理をお気に入り登録できる
- お気に入り登録した料理を一覧表示できる

単に画面を表示するだけではなく、これまで学習したReactの機能を適切に組み合わせて実装することが今回の課題です。

---

# 2. 開発するアプリ

## Recipe Finder

料理名を入力すると、条件に一致する料理を検索できるWebアプリケーションを開発します。

料理データの取得には、外部APIである「TheMealDB」を利用します。

アプリには、最低でも次の3つの画面を作成してください。

### 検索画面

料理を検索し、検索結果を確認する画面です。

### 料理詳細画面

検索結果から選択した料理について、詳しい情報を確認する画面です。

### お気に入り画面

お気に入りに登録した料理を一覧で確認する画面です。

---

# 3. 使用するAPI

今回の演習では「TheMealDB」を使用します。

TheMealDBは、料理やレシピに関するデータをJSON形式で取得できるAPIです。

今回の演習では、教育用途で利用できるテストAPIキー「1」を使用します。

## 料理名から検索

```
https://www.themealdb.com/api/json/v1/1/search.php?s=料理名
```

例えば、`chicken`を検索する場合は次のURLになります。

```
https://www.themealdb.com/api/json/v1/1/search.php?s=chicken
```

## IDから料理の詳細を取得

```
https://www.themealdb.com/api/json/v1/1/lookup.php?i=料理ID
```

例えば、IDが`52772`の場合は次のURLになります。

```
https://www.themealdb.com/api/json/v1/1/lookup.php?i=52772
```

APIからどのようなJSONが返ってくるかは、実際にURLへアクセスしたり、ブラウザの開発者ツールを利用したりして確認してください。

TheMealDB公式APIでは、料理名検索とIDによる詳細取得が提供されています。

# 4. 必須要件

ここから記載する内容は、すべて実装してください。

---

## 4-1. 料理を検索できる

検索画面には、料理名を入力するフォームを作成してください。

利用者が料理名を入力して検索を実行すると、TheMealDBから料理データを取得します。

入力値はReactで管理してください。

### 必須機能

- 料理名を入力できる
- 検索を実行できる
- 入力された料理名を利用してAPI通信を行う
- 取得した検索結果を画面に表示する

検索フォームのデザインや配置は自由です。

---

## 4-2. 検索結果を一覧表示する

APIから取得した料理を一覧表示してください。

一覧には最低でも、次の情報を表示してください。

- 料理名
- 料理画像

検索結果が複数存在する場合は、すべて表示してください。

一覧表示には、これまで学習した`map`を利用してください。

また、Reactが各データを識別できるよう、適切な`key`を設定してください。

---

## 4-3. 検索結果が存在しない場合に対応する

検索した料理が必ず見つかるとは限りません。

検索結果が0件だった場合は、利用者が状況を理解できる表示を行ってください。

例：

```
料理が見つかりませんでした。
```

常に同じ画面を表示するのではなく、データの状態に応じて表示を切り替えてください。

---

## 4-4. 料理詳細画面を作成する

検索結果から料理を選択すると、その料理の詳細画面へ移動できるようにしてください。

画面遷移にはReact Routerを使用します。

詳細画面では、URLなどから対象となる料理のIDを取得し、そのIDを利用して料理詳細APIへアクセスしてください。

詳細データの取得には`useEffect`を使用してください。

---

## 4-5. 料理の詳細情報を表示する

料理詳細画面には、最低でも次の情報を表示してください。

- 料理名
- 料理画像
- カテゴリ
- 地域
- 作り方
- 材料

TheMealDBでは、データによって一部の項目が存在しない場合があります。

取得したデータを確認し、必要に応じて表示を制御してください。

---

# 5. 材料データについて

TheMealDBの材料データは、通常の配列とは少し異なる形で格納されています。

例えば、次のようなプロパティがあります。

```
strIngredient1
strIngredient2
strIngredient3
...
```

材料の分量についても、

```
strMeasure1
strMeasure2
strMeasure3
...
```

という形式で格納されています。

`strIngredient1`と`strMeasure1`、`strIngredient2`と`strMeasure2`のように、同じ番号のデータが対応しています。

どのように一覧として表示するかは、自分で考えて実装してください。

空文字やデータが存在しない項目については、画面に表示する必要はありません。

# 6. お気に入り機能を実装する

利用者が気になった料理を、お気に入りとして登録できるようにしてください。

お気に入り情報は複数の画面から利用するため、Contextを利用して管理してください。

---

## 6-1. お気に入り登録

料理をお気に入りへ追加できる機能を作成してください。

少なくとも料理詳細画面からお気に入り登録できるようにしてください。

同じ料理を何度も登録した場合に、同じ料理が大量に追加されないようにしてください。

---

## 6-2. お気に入り一覧

お気に入り画面を作成し、登録した料理を一覧表示してください。

お気に入りが1件も存在しない場合についても、適切な表示を行ってください。

例：

```
お気に入りの料理はありません。
```

---

## 6-3. お気に入り解除

登録した料理を、お気に入りから削除できるようにしてください。

削除後は画面にも結果が反映されるようにします。

# 7. 画面遷移


React Routerを使用して、それぞれ別のURLで表示できるようにしてください。

URLの設計は自由です。

例えば、

```

```

```

```

```

```

ただし、このURL構成をそのまま使用する必要はありません。
